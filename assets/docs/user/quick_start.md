# Quick Start

Last updated: 2026-09-16

## What The Application Does

AEGIS Geospatial View is a chat-driven geospatial workspace. The user describes a location and requested action in plain language, and the system returns map-focused results with session context and overlays when applicable.

## Primary Screens

- Workspace (`/`)
- Geodata (`/geodata`)
- Settings (`/settings`) with Models, Model Providers, and Geospatial Access tabs

## Quick Start Journey

1. Open the app.
2. Ask for a place or coordinates and what you want to see.
3. Wait for the assistant response and map session.
4. Review the output and overlay controls.
5. Use the Operations Bar to move to Geodata or Settings. Settings keeps model
   selection, model-provider credentials, local Ollama controls, and
   geospatial access in one place.

The default geospatial workflow uses public sources and does not require a
provider key. Select an agent model in Settings → Models only when the initial
configuration is missing or you want to switch between a compatible cloud
model and a locally installed Ollama model.
